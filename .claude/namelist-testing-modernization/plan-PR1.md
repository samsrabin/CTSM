## Context

The repo-level design (`.claude/namelist-testing-modernization/design.md`) lays out a manifest-driven, pytest-parametrized rewrite of `bld/unit_testers/build-namelist_test.pl` landing across 11 PRs. PR1 establishes the scaffold every subsequent PR builds on. No test category from the Perl script is ported in PR1 beyond the two trivial smoke cases (`-help`, `-version`); the bulk of PR1 is infrastructure.

Key contract PR1 establishes:

- **Manifest is the source of truth.** `cases.yaml` (generated by `extract_cases.pl`) enumerates every assertion the Perl script makes. Every ported pytest case has an `id` matching a YAML entry.
- **Three gates for "PR ready":** `check_python.sh` (lint), `check_coverage.py` (coverage), `check_coverage.py --parity` (perl/pytest outcome match for ported cases). Reviewer agent runs all three. All three exit zero or the PR is not ready.
- **Pytest-native structure.** `@pytest.mark.parametrize` over case slices, fixtures in `conftest.py`. The first place CTSM uses pytest's parametrize/fixtures (existing `python/ctsm/test/` is unittest-style).

When the PR lands: PR1+infra exists, smoke test passes, coverage check says `2 / ~3400 ported`, parity check says `0 mismatches`, lint passes. Nothing else changes — Perl harness still invoked identically, no CTSM-shared file touched.

## Task 1: Build the extractor and produce the initial cases.yaml

**Files:**
- Create: `bld/unit_testers/extract_cases.pl`
- Generate (commit the output): `bld/unit_testers_python/cases.yaml`

The extractor has two modes:

- **default (enumerate mode):** runs the perl test, captures every assertion's context, writes `cases.yaml`. Pass/fail outcomes are NOT recorded (the goal is to enumerate what the perl script tests, not whether it currently passes on this machine).
- **`--run-mode <outfile>`:** runs the perl test, captures pass/fail per case, writes outcomes as `<outfile>` (JSON) for `check_coverage.py --parity` to consume. Does not touch `cases.yaml`.

- [ ] **Step 1: Write the extractor**

```perl
#!/usr/bin/env perl
#
# extract_cases.pl — instrument build-namelist_test.pl and emit the
# manifest of every Test::More assertion it makes.
#
# Default (enumerate mode):   ./extract_cases.pl
#   → writes ../unit_testers_python/cases.yaml
# Run mode:                   ./extract_cases.pl --run-mode outcomes.json
#   → writes outcomes.json with {case_id → "pass"|"fail"} mapping
#
# Used by:
#   - PR-level checked-in manifest regeneration (default mode)
#   - check_coverage.py --parity (run mode, ephemeral output)

use strict;
use warnings;
use FindBin qw($Bin);
use Cwd qw(abs_path);
use English;
use Getopt::Long;

# --- arg parsing ----------------------------------------------------------
my $run_mode_outfile;
GetOptions("run-mode=s" => \$run_mode_outfile) or die "usage: extract_cases.pl [--run-mode <outfile>]\n";
my $enumerate_mode = !defined($run_mode_outfile);

# --- captured state -------------------------------------------------------
our $current_category   = "uncategorized";
our $current_phys       = undef;
our %current_env_run    = ();
our $current_bldnml_argv = undef;     # arrayref
our @current_infile_sources = ();
our @current_setup_files = ();
our @cases = ();                       # accumulated case records

# Each case record is a hashref of the schema in design.md §6, plus an
# internal `_perl_passed` slot used only in run-mode.

# --- hooks ----------------------------------------------------------------

# Watch print() to STDOUT for "=== Some banner ===" lines, derive category.
# Implemented as a tied STDOUT or as a Test::Builder->output() handler — see
# Test::More docs. Section headers in build-namelist_test.pl look like:
#     print "\n==================================================\n";
#     print "Run simple tests \n";
# We watch the second line (text between two banner-of-equals lines).

# Wrap make_env_run / make_config_cache / cat_and_create_namelistinfile
# in the main:: namespace so we see what context each assertion runs in.
# These subs are defined at the top of build-namelist_test.pl. The wrapper
# preserves their original behavior while updating our captured state.

# Wrap system() to capture the most-recent bldnml command line. This is
# robust because the perl script only shells out to build-namelist via
# system(); every system() call is one bldnml invocation.

# Hook Test::Builder->ok so every assertion produces a case record. The
# description (third arg to is/isnt/ok/like) becomes the case description;
# pass/fail goes into _perl_passed (run-mode only).

# Implementation skeleton:
{
    no warnings 'redefine';
    require Test::Builder;
    my $orig_ok = Test::Builder->can('ok');
    *Test::Builder::ok = sub {
        my ($self, $test, $name) = @_;
        my $ret = $orig_ok->($self, $test, $name);
        push @cases, _snapshot_case($name, $test);
        return $ret;
    };
}

sub _snapshot_case {
    my ($desc, $passed) = @_;
    my (undef, $file, $line) = caller(2);   # the user's is/isnt call site
    return {
        id          => _derive_id($desc),
        category    => $current_category,
        description => $desc,
        bldnml_argv => [ @{ $current_bldnml_argv // [] } ],
        env_run     => { %current_env_run },
        phys        => $current_phys,
        infile      => { sources => [ @current_infile_sources ] },
        setup_files => [ @current_setup_files ],
        expect      => { exit_zero => $passed ? 1 : 0,
                         files => [], greps => [] },
        xfail       => undef,
        source      => { perl_file => $file, line => $line },
        ported      => 0,
        stale       => 0,
        stale_reason => undef,
        _perl_passed => $passed ? 1 : 0,
    };
}

sub _derive_id {
    my ($desc) = @_;
    # Strategy: <category>/<slugified-description>. If description is just
    # "options: ...", strip the prefix and slugify the option string. If
    # description is a key from a hash like %failtest, use it directly.
    my $slug = lc $desc;
    $slug =~ s/^options:\s*//;
    $slug =~ s/[^a-z0-9._-]+/-/g;
    $slug =~ s/^-+|-+$//g;
    $slug = substr($slug, 0, 80);          # cap length
    return "$current_category/$slug";
}

# --- invoke build-namelist_test.pl ----------------------------------------
# Run with -no-test so dataset existence checks are skipped — the extractor
# does not need inputdata to enumerate cases.
@ARGV = ("-no-test");
do "$Bin/build-namelist_test.pl"
  or die "ERROR: failed to run build-namelist_test.pl: $! / $@\n";

# --- emit output ---------------------------------------------------------
if ($enumerate_mode) {
    _write_cases_yaml("$Bin/../unit_testers_python/cases.yaml");
} else {
    _write_outcomes_json($run_mode_outfile);
}

sub _write_cases_yaml { ... }     # hand-rolled YAML emitter, no XS deps
sub _write_outcomes_json { ... }  # tiny JSON emitter, no XS deps
```

The hooking and the YAML/JSON serialization are sketched here; the executor implements them in full per the design schema in `design.md §6`. Use hand-rolled emitters (no `YAML::Tiny` / `JSON::PP` deps) so the extractor runs in the same Perl environment that `build-namelist_test.pl` uses today.

```python
"""Helpers for the pytest-based build-namelist test suite."""

from __future__ import annotations

import json
import subprocess
from dataclasses import dataclass, field
from pathlib import Path
from typing import Iterable, Optional

import yaml


@dataclass
class XFailSpec:
    condition: Optional[str] = None
    reason: Optional[str] = None
    strict: bool = True


@dataclass
class CaseExpect:
    exit_zero: bool = True
    files: list = field(default_factory=list)
    greps: list = field(default_factory=list)


@dataclass
class CaseInfile:
    sources: list = field(default_factory=list)


@dataclass
class CaseSource:
    perl_file: Optional[str] = None
    line: Optional[int] = None


@dataclass
class Case:
    id: str
    category: str
    description: str
    bldnml_argv: list
    env_run: dict
    phys: Optional[str]
    infile: CaseInfile
    setup_files: list = field(default_factory=list)
    expect: CaseExpect = field(default_factory=CaseExpect)
    xfail: Optional[XFailSpec] = None
    source: CaseSource = field(default_factory=CaseSource)
    ported: bool = False
    stale: bool = False
    stale_reason: Optional[str] = None


@dataclass
class RunResult:
    returncode: int
    stdout: str
    stderr: str
    produced_files: list


_CASES_YAML = Path(__file__).parent / "cases.yaml"


def load_cases(
    *,
    category: Optional[str] = None,
    ids: Optional[Iterable[str]] = None,
    ported_only: bool = True,
) -> list[Case]:
    """Load cases.yaml, optionally filtered.

    Args:
        category: if given, only return cases with this category.
        ids: if given, only return cases whose id is in this iterable.
        ported_only: if True (default), skip cases with ported=False.
            Set False for tooling (check_coverage.py).
    """
    with open(_CASES_YAML) as f:
        raw = yaml.safe_load(f)
    cases = [_case_from_dict(d) for d in raw]
    if category is not None:
        cases = [c for c in cases if c.category == category]
    if ids is not None:
        idset = set(ids)
        cases = [c for c in cases if c.id in idset]
    if ported_only:
        cases = [c for c in cases if c.ported]
    return cases


def _case_from_dict(d: dict) -> Case:
    return Case(
        id=d["id"],
        category=d["category"],
        description=d["description"],
        bldnml_argv=list(d.get("bldnml_argv") or []),
        env_run=dict(d.get("env_run") or {}),
        phys=d.get("phys"),
        infile=CaseInfile(sources=list((d.get("infile") or {}).get("sources") or [])),
        setup_files=list(d.get("setup_files") or []),
        expect=CaseExpect(
            exit_zero=(d.get("expect") or {}).get("exit_zero", True),
            files=list((d.get("expect") or {}).get("files") or []),
            greps=list((d.get("expect") or {}).get("greps") or []),
        ),
        xfail=_xfail_from_dict(d.get("xfail")),
        source=CaseSource(
            perl_file=(d.get("source") or {}).get("perl_file"),
            line=(d.get("source") or {}).get("line"),
        ),
        ported=bool(d.get("ported")),
        stale=bool(d.get("stale")),
        stale_reason=d.get("stale_reason"),
    )


def _xfail_from_dict(d: Optional[dict]) -> Optional[XFailSpec]:
    if not d or not d.get("condition"):
        return None
    return XFailSpec(
        condition=d["condition"],
        reason=d.get("reason"),
        strict=bool(d.get("strict", True)),
    )


def infile_writer(sources: Iterable[Path], dest: Path) -> Path:
    """Concatenate user_nl_clm sources into a &clm_settings ... / file."""
    lines = ["&clm_settings\n", "\n"]
    for src in sources:
        with open(src) as f:
            for line in f:
                lines.append(" " + line)
    lines.append("\n/\n")
    dest.write_text("".join(lines))
    return dest
```

```python
    bldnml_path,
    inputdata_root,

    base_argv = [
        str(bldnml_path),
        "-verbose",
        "-csmdata", inputdata_root,
        "-configuration", "clm",
        "-structure", "standard",
        "-glc_nec", "10",
        "-no-note",

    def _run(argv, *, infile=None, extra_env=None, setup_files=()) -> RunResult:
        for fname in setup_files:
            (tmp_workdir / fname).touch()
        cmd = list(base_argv)
        if infile is not None:
            cmd += ["-infile", str(infile)]
        cmd += list(argv)
        env = os.environ.copy()

            env.update(extra_env)

            cmd, capture_output=True, text=True, env=env, cwd=str(tmp_workdir),
        )
        produced = [p for p in ("lnd_in", "drv_flds_in") if (tmp_workdir / p).exists()]
        return RunResult(
            returncode=proc.returncode,
            stdout=proc.stdout,
            stderr=proc.stderr,
            produced_files=produced,
        )

    return _run
```

## Task 3: Proof-of-life smoke test

**Files:**
- Create: `bld/unit_testers_python/test_sys_smoke.py`

The smoke test runs the two simplest perl cases (`-help` and `-version`) through pytest's parametrize, exercising the full fixture chain end-to-end. After this task, the suite has its first passing cases and the parametrize-from-manifest idiom is established.

- [ ] **Step 1: Write the smoke test**

```python
"""Smoke tests: build-namelist runs at all (-help, -version)."""

import pytest

from helpers import load_cases


_SMOKE_CASES = load_cases(category="smoke", ported_only=True)


@pytest.mark.sys
@pytest.mark.parametrize("case", _SMOKE_CASES, ids=lambda c: c.id)
def test_sys_smoke(case, build_namelist):
    result = build_namelist(case.bldnml_argv)
    # The perl assertion is just "does the subprocess return at all" —
    # we mirror that here. For -help / -version build-namelist exits
    # successfully (returncode 0); the perl wrapping with eval{ system }
    # only catches system() itself failing to fork, not child non-zero.
    assert result.returncode == 0, (
        f"build-namelist {case.bldnml_argv} returned {result.returncode}\n"
        f"--- stderr ---\n{result.stderr}\n"
        f"--- stdout ---\n{result.stdout}\n"
```

## Task 4: check_coverage.py (coverage + parity subcommands)

**Files:**
- Create: `bld/unit_testers_python/check_coverage.py`

Per the design (§9.1 + §9.2), this tool is the gate for both coverage and parity. PR1 implements both subcommands fully so they work from day one.

- [ ] **Step 1: Write the script**

```python
#!/usr/bin/env python3
"""Coverage and parity gates for the build-namelist test rewrite.

Usage:
    python check_coverage.py             # coverage report
    python check_coverage.py --parity    # parity check against perl

Exits zero on success, non-zero on any mismatch or coverage gap.
"""

from __future__ import annotations

import argparse
import json
import re
import subprocess
import sys
import tempfile
from pathlib import Path

import yaml


_HERE = Path(__file__).resolve().parent
_CASES_YAML = _HERE / "cases.yaml"
_REPO_ROOT = _HERE.parent.parent
_PERL_EXTRACTOR = _REPO_ROOT / "bld" / "unit_testers" / "extract_cases.pl"


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument(
        "--parity", action="store_true",
        help="Run the parity gate (perl/pytest outcome comparison).",
    )
    parser.add_argument(
        "--perl-outcomes", type=Path, default=None,
        help="Cached perl outcomes JSON (from extract_cases.pl --run-mode). "
             "If omitted with --parity, the perl suite is re-run.",
    )
    args = parser.parse_args()

    if args.parity:
        return _parity(args.perl_outcomes)
    return _coverage()


def _coverage() -> int:
    manifest = _load_manifest()
    collected = _pytest_collect()
    manifest_ids = {c["id"] for c in manifest}
    ported_ids = {c["id"] for c in manifest if c.get("ported")}
    stale_ids = {c["id"] for c in manifest if c.get("stale")}
    unaccounted = manifest_ids - ported_ids - stale_ids

    missing_in_collection = ported_ids - collected
    extra_in_collection = collected - ported_ids - stale_ids

    print(f"Manifest: {len(manifest_ids)} cases")
    print(f"  ported: {len(ported_ids)}")
    print(f"  stale:  {len(stale_ids)}")
    print(f"  neither (unaccounted): {len(unaccounted)}")
    print(f"Pytest collected: {len(collected)} cases")

    bad = 0
    if missing_in_collection:
        print(f"\nERROR: {len(missing_in_collection)} cases marked ported "
              "but not collected by pytest:")
        for cid in sorted(missing_in_collection):
            print(f"  - {cid}")
        bad += 1
    if extra_in_collection:
        print(f"\nERROR: {len(extra_in_collection)} pytest cases not in "
              "manifest as ported (possible drift):")
        for cid in sorted(extra_in_collection):
            print(f"  - {cid}")
        bad += 1
    return 1 if bad else 0


def _parity(cached_outcomes: Path | None) -> int:
    manifest = _load_manifest()
    ported = [c for c in manifest if c.get("ported")]
    perl_outcomes = _perl_outcomes(cached_outcomes)
    pytest_outcomes = _pytest_outcomes()

    mismatches = []
    for case in ported:
        cid = case["id"]
        p_out = perl_outcomes.get(cid)
        py_out = pytest_outcomes.get(cid)
        if p_out is None:
            mismatches.append(f"{cid}: perl=<MISSING> pytest={py_out}")
            continue
        if py_out is None:
            mismatches.append(f"{cid}: perl={p_out} pytest=<MISSING>")
            continue
        if p_out != py_out:
            mismatches.append(f"{cid}: perl={p_out} pytest={py_out}")

    if mismatches:
        print(f"PARITY FAILURE: {len(mismatches)} mismatches:")
        for m in mismatches:
            print(f"  {m}")
        return 1
    print(f"PARITY OK: {len(ported)} cases agree.")
    return 0


def _load_manifest() -> list[dict]:
    return yaml.safe_load(_CASES_YAML.read_text())


def _pytest_collect() -> set[str]:
    """Return the set of case IDs pytest collects, derived from node IDs."""
    out = subprocess.check_output(
        ["pytest", "--collect-only", "-q", "--no-header"],
        cwd=str(_HERE), text=True,
    )
    # pytest node IDs look like: test_sys_smoke.py::test_sys_smoke[smoke/help]
    ids = set()
    pat = re.compile(r"\[([^\]]+)\]")
    for line in out.splitlines():
        m = pat.search(line)
        if m:
            ids.add(m.group(1))
    return ids


def _pytest_outcomes() -> dict[str, str]:
    """Run the pytest suite and return {case_id → 'pass'|'fail'}."""
    proc = subprocess.run(
        ["pytest", "--tb=no", "-q", "--no-header", "-p", "no:warnings"],
        cwd=str(_HERE), capture_output=True, text=True,
    )
    # Lines look like: "test_sys_smoke.py::test_sys_smoke[smoke/help] PASSED"
    outcomes = {}
    pat = re.compile(r"\[([^\]]+)\]\s+(PASSED|FAILED|XFAIL|XPASS)")
    for line in (proc.stdout + proc.stderr).splitlines():
        m = pat.search(line)
        if not m:
            continue
        cid, status = m.group(1), m.group(2)
        outcomes[cid] = "pass" if status in {"PASSED", "XFAIL"} else "fail"
    return outcomes


def _perl_outcomes(cached: Path | None) -> dict[str, str]:
    if cached:
        return json.loads(cached.read_text())
    with tempfile.NamedTemporaryFile(suffix=".json", delete=False) as tf:
        outfile = Path(tf.name)
    subprocess.check_call(
        ["perl", str(_PERL_EXTRACTOR), "--run-mode", str(outfile)],
        cwd=str(_REPO_ROOT / "bld" / "unit_testers"),
    )
    return json.loads(outfile.read_text())


if __name__ == "__main__":
    sys.exit(main())
```
