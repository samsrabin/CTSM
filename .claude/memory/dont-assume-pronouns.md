On 2026-08-27 I referred to the user as "he/his" several times in one message
while describing work on the `adrianna-moss-grass-pft` branch. The user:
*"Don't assume 'his'!"*

Applies to everyone who comes up in this project -- the user, the branch
namesakes, upstream CTSM and FATES developers, issue reporters. A name is not
evidence of pronouns, and neither is a branch name.

**Why:** guessing wrong misgenders a real person; the neutral default never
does. The user has not stated pronouns and there is no reason to need them.

**How to apply:** address the user in the second person -- "your branch", "the
names you gave me" -- which is both correct and better writing. For third
parties, use they/them. This covers commit messages, plan and spec prose,
comments, and dispatch prompts to subagents, not just chat.
